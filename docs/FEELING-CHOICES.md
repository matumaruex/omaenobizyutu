# 気持ちを選ぶ入口

文章入力と「近い感覚から選ぶ」を切り替える。選択は最大2つで、補足文は任意。「まだわからない」は他の項目と排他的。選ぶだけではAPIを呼ばず、「展示する」で生成する。

現在の15タグの方向を取りこぼしにくいよう、以下の8項目を用意する。右列は設計上のカバー範囲であり、コードでタグへ固定変換する対応表ではない。

| 表示               | 意識したタグの方向 |
| ------------------ | ------------------ |
| 穏やか・あたたかい | 安心、慈しみ       |
| うれしい・楽しみ   | 喜び、期待、希望   |
| 気になる・驚き     | 好奇心、畏敬       |
| 寂しい・ひとり     | 寂しさ、孤独       |
| 懐かしい・心残り   | 懐かしさ、未練     |
| 悲しい・ぽっかり   | 悲しみ、喪失感     |
| 不安・そわそわ     | 不安               |
| 怒り・もどかしい   | 怒り               |

選択ラベルは「近い感覚：…」、任意の補足は「自分の言葉：…」として既存のtextへまとめ、MiMoによるタグ解釈→候補24件の抽選→MiMoによる8作品選定へ渡す。補足の文脈・否定を優先し、中黒で並んだ言葉すべてを本人の感情と断定しないよう指示する。履歴にも同じ入力を保存する。全文で800文字以内、超えたら送信前に表示し、切り捨てない。

「まだわからない」だけならタグ解釈後のtags/negatedTagsを空にして、感情を推測したタグで絞らない。補足があれば通常の文脈解釈を使う。候補の抽選、作者上限、直近展示の再登場調整は従来どおり。全作品が均等に出る保証ではない。

通常のMiMo呼び出しは従来どおり2回。追加の推論工程はなく、ラベルと短い指示の分だけ入力トークンが増える。選定の実際の解釈品質は利用しながら確認する。今回の検証は通信をモックし、有料APIは呼ばない。
