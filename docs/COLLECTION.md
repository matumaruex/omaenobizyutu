# 作品データ

参照元：[matumaruex/kaiga-data](https://github.com/matumaruex/kaiga-data)。アプリ専用の別作品リストや固定16枚は使用しません。

初期DBはコミット `c7e3474f15b5d5d9a7fb6d221ecb8d52b0fa51c9` の200作品（シカゴ美術館51、メトロポリタン美術館149）。画像台帳には保留作が含まれますが、`data/artworks.json` の登録作品だけを使います。33作品は感情タグ0件で、現段階のタグによる一次抽出では候補になりません。

制作意図・研究の解釈・視覚的手掛かり・不確かな事項・選定上の注意をDBから引き継ぎます。作者の感情と鑑賞者の感情は区別します。主タグ・補助タグの両方が候補検索の対象です。

画像はDBに登録されたURLから取得します。旧アプリの画像を本体へ同梱する処理は削除しました。`tests/fixtures/` の4枚はHTTPを模擬するブラウザ試験とハッシュ検査の入力だけに使用し、公開アプリの作品選定・画像配信では参照しません。

初期JSONの生成は `npm run catalog:sync`、既存チェックアウトからは `npm run catalog:sync -- --source /path/to/kaiga-data`。200作品のJSONは画像の一括取得ではありません。通常の更新はアプリサーバーが約24時間のキャッシュ期限後に行い、GitHubの同一コミットを固定して整合を検証します。

試験登録での公開画像フラグ、台帳のSHA256、利用条件のリンクを確認します。画像本体はJPEG・ハッシュ照合後に配信します。DB記載の出典や研究解釈を今回再調査したわけではなく、人間による最終画像視認・解釈承認・公開審査の完了とも同一視しません。今回の配信先は既存の認証保護された確認用サイトです。
