# 作品資料

ローカル確認日：2026年10月17日（日本時間）。16点すべて実在するシカゴ美術館所蔵の絵画です。

この環境では公式APIとIIIFに接続できなかったため、公開済みの保存資料を用いました。現行APIへ再照会したという意味での「検証済み」ではありません。個別の画像権利記録・出典ID・画像ファイルのハッシュ一致・作品が描く対象を確認したサンプルです。

`src/data/provenance.json`の各レコードに、次を保存しています。

- 美術館の作品ID、題名、所蔵番号、作品ページ、参照用の公式画像ID。
- 元のWikimedia Commonsファイルページと画像URL。
- 個別のPublic Domain Mark、ライセンスURL、クレジット。
- 保存元が記録する取得日、バイト数、SHA-256。
- 実際に読み出したGitHub画像ファイルのURL（コミット固定）。

画像は保存元のファイルを未改変で同梱しています。全ファイルのハッシュを照合し、コンタクトシートで作品と題名を確認しました。`collection.json`の幅と高さには同梱JPEGの実寸を使います。参照用の公式画像IDと、同梱するCommons画像が画素単位で同一とは主張していません。

基本データはシカゴ美術館の公開資料に由来します。公式APIデータの原則CC0と、説明フィールド`description`のCC BY 4.0の区別は、[公式のライセンス記録](https://github.com/art-institute-of-chicago/api-data/blob/8936f25879fd688fc2412436e5df4e30402bd081/json/info.json)を参照しています。公式説明本文と、保存元アプリの解説・鑑賞文はこのアプリにコピーしていません。

今回の`facts`は「誰が何を描いたか」「画面に何が見えるか」に絞った独自の短文です。`interpretation`、感情スコア、展示の役割はこのアプリの編集上の解釈で、美術史上の事実とは分けて扱います。作者の制作動機や心理を断定していません。
