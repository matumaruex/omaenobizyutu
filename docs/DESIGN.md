# 展示室のデザイン基準

2026-11-14、入口を鏡のついた扉へ変更。過去の白い壁・石調の床や、全面木製の案は現行の展示室の内装ではありません。

## 入口と室内

- 入口は、内面へ入ることを表す鏡のついた扉の写実的な背景と、柔らかい白の明朝体。緑の壁に午後の日差しが入り、鏡には静かな回廊が映る。古典的なアーチ・付け柱・壁のモールディングで、歴史ある美術館の雰囲気をつくる。
- 同じ意匠の横長・縦長のWebP背景を同梱し、画面の縦横比で切り替える。横長では左にタイトルと入室ボタン、縦長では扉の上にタイトル、下に入室ボタンを置く。文字や操作は背景へ焼き込まず、HTMLのまま重ねる。入口用フォントは必要な文字だけを同梱する。
- 室内の壁は落ち着いた青（素材の基色 `#597f90`）。床と天井は同じ淡い木材色で、同梱の `room-pale-ash.webp` を共有する。壁に木目は重ねない。
- ツヤのない表面と柔らかい陰影。天井に照明器具や装飾を加えず、壁・床・天井の境界を淡い陰影で見せる。
- 額は控えめな金色（`#bba16f`）、オフホワイトのマットと薄い接地影を使う。画像は元の縦横比と色を保つ。
- 入室後の常設表示は「気持ちを教える」と小さな「部屋から出る」。入力欄は必要なときだけ開く。

## 構図と操作

- 正八角形の1室。MiMoが選んだ8作品を8面に1作品ずつ置き、部屋の中心から見回す。歩行・床タップ移動・自動回転・ズームは加えない。
- 正面と左右の隣接面を見渡せる横視野角75度を基準とする。左右は隣の面が約3分の1ずつ見える構図。横長画面では縦視野角を最低50度にし、上下の収まりを保つ。
- 額込みの横幅は壁幅の78％を目安にし、縦長作品は高さ3m以内で比率を維持する。
- ドラッグ・スワイプ・矢印キーで見回す。スマホの上下感度は横方向の2分の1。マウスと矢印キーは別の設定。
- 入室は約0.65秒のフェード。動きの低減設定では入室フェードを省く。作品の段階的な表示も維持する。

## 作品と解説

作品を選ぶと画像と「解説を開く」を表示する。画像枠は縦横比に合わせ、画面高から操作部分の余地を確保する。解説パネルは灰ベージュと茶系の文字を使い、弱い暗色とぼかしで背景の部屋を残す。

鑑賞者向け本文は作品DBの `visitor_explanation` を段落ごと表示する。未登録の旧データでは従来の視覚的特徴・制作背景・専門的解釈へ切り替える。資料のある作者発言は作品への直接の発言と連作・制作姿勢への関連発言を区別し、根拠のない作者意図は表示しない。MiMoの短い選定理由は任意に開ける。画像・出典・所蔵情報は末尾へまとめ、閲覧による追加AI呼び出しは行わない。

## 実装と確認箇所

- `src/lib/layout.ts`：部屋の寸法・画角・額の収まり・配置。
- `src/lib/room-materials.ts`：素材の基色、床・天井の木目、陰影。
- `src/components/Room.tsx`：素材の表示、額、視点操作。描画時の色には面ごとの調整や照明も影響する。
- `src/app/globals.css`、`src/components/ArtworkView.tsx`：入口、パネル、画像・解説の表示。

背景・木目・フォントは同梱資産を使用する。表示のたびに画像生成APIを呼ばない。陰影のためのシャドウマップや追加の後処理は使わない。

見た目を変更した場合は、正面の縦長作品・横長作品・空の部屋・入力欄・解説を、変更に応じてPCとスマホ相当で確認する。承認済みデザインを説明書の整理だけで変更しない。
