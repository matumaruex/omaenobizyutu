# 展示室のデザイン基準

2026年10月21日。自分の気持ちから生まれた展示を、一人で自由に見つける体験。

- 入室後に残す表示は「気持ちを教える」と小さな「部屋から出る」。タイトルや説明は置かない。
- 正八角形の部屋の中心からドラッグ／スワイプで8面を見回す。歩行、床タップ移動、自動回転、ズームは加えない。
- 壁は温かい白、床は明るいマットな石の印象。天井と壁の境、床との境、隅に淡い陰影をつける。
- 天井は装飾やライトの形を置かない。室内の柔らかい明るさは、見える照明器具を使わずにつくる。
- MiMoは8作品を選び、各壁の中央に1作品ずつ、同じ最大寸法で額装する。スマホで正面の額全体が見え、絵の細部も感じられる距離にする。
- 細い落ち着いた色の額、オフホワイトのマット、薄い接地影で額装する。画像は縦横比と元の色を保つ。
- 入口と入力欄は紙色と茶系の文字、作品・解説パネルは床や額になじむ灰ベージュと茶系の文字で揃える。背景を白く覆わず、淡い暗色と弱いぼかしで部屋の気配を残す。入力欄は必要なときだけ開く。
- 絵の段階的なフェードを維持し、入室だけ短いフェードを使う。動きの低減設定では入室のフェードも省く。

`src/lib/layout.ts` が部屋の寸法・画角・配置を管理する。壁と床の陰影、微細な素材感、額の影は `src/lib/room-materials.ts` で小さなテクスチャを生成する。追加の画像通信、フォント通信、影用の描画パス、画像生成APIは使わない。額の側面は照明で描画し、絵とマットの色は照明の強さで変わらないようにする。

画面確認は正面の縦長作品、横長作品、空の部屋、入力欄を基準にし、PCとスマホで行う。作品はGitHubのDBを唯一の参照元とし、展示作成時にMiMoで選定する。
