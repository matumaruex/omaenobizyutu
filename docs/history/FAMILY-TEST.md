# 家族向けの試験用入口

> **過去の構成記録（2026-11-12追記）:** 利用者が家族用を不要としたため、現在の運用対象ではありません。以下は当時の手順です。通常作業で家族用ブランチの復活・同期・再配信をしないでください。既存の配信や公開例外が削除済みであるという意味ではありません。現在の案内は [開発ガイド](../DEVELOPMENT-GUIDE.md)、履歴への接続は [接続・調査の手順](../OPERATIONS.md) を参照してください。

`codex/museum-family-test` のPreviewを招待用の入口に使います。鑑賞・感情入力・MiMo選定・作品解説は通常の確認用アプリと同じです。家族用エイリアスだけにVercelの `alias-protection-override` を設定し、試す人のVercel登録・ログインを不要にします。

招待用URL: https://bijutsukan-git-codex-museum-family-test-matumaruexs-projects.vercel.app/

このブランチには `MUSEUM_GUEST_MODE=1` を設定します。設定が欠けても `VERCEL_GIT_COMMIT_REF=codex/museum-family-test` の場合は履歴を非公開にします。サーバーの `GET /api/history` と `GET /api/usage` は保存先へ接続する前に403を返します。画面からも試験用の履歴・料金・選定確認の操作を隠し、入力が試験・改善のために運営側へ保存されることを表示します。画像読み込み結果の報告は継続します。

これはゲスト用デプロイの設定であり、個人を識別するログイン機能ではありません。所有者用の `codex/museum-preview` はVercelの認証保護を維持し、これまでの全履歴を読めます。Codexも認証付きコネクターで所有者用の履歴を確認します。所有者用の共有リンクを発行しないでください。

両方とも既存PreviewのMiMo・Redis接続を利用し、名前空間・累計を維持します。1展示につきタグ判定・最終選定の原則2回を個別に数えます。招待した人の生成も同じ累計送信枠（2026-11-10に利用者の依頼で全体50回から200回へ変更）に含まれ、API料金は所有者のMiMoアカウントに発生します。自動再試行は行いません。上限に達した場合、招待者への連絡を案内します。

以前の `_vercel_share` 付きリンクは有効な状態でも、LINEで開くとログイン画面に進むとの報告がありました。原因は特定していません。現在は共有コードやCookieによる許可の保存に頼らず、招待用URL自体を公開します。このURLを知る人は利用でき、生成は上記の共通上限に含まれます。プロジェクト全体の認証を無効にしたり、自動化用のバイパスキーを共有したりしません。

配信を更新した場合も、招待用エイリアスの `protectionBypass["*"].scope` が `alias-protection-override` であることと、所有者用のプロジェクト認証が維持されていることを確認してください。招待用の `/api/history` と `/api/usage` は引き続き403であることを確認します。公開を終了する場合は、このエイリアスだけの例外を取り消します。認証付きコネクターによる取得成功だけでは未ログインで開ける証拠にならないため、実際の未ログインのブラウザでも確認してください。

アプリの変更を招待用にも反映するときは、試験済みコミットを `codex/museum-family-test` に通常の早送りで反映します。元のDBは引き続き約24時間のキャッシュで読み直します。

2026-11-08: 再登場調整用に、このブラウザで表示した直近5展示の作品IDだけをlocalStorageへ保存します。入力文・解説は端末側の記録に含めず、履歴一覧も表示しません。生成時に最大5×8件のIDを送り、プログラムが候補抽選の重みを調整します。MiMoには直近展示のIDを渡しません。共有の運営履歴を読み込んで補充することはありません。

保存はURLのオリジン単位です。自分用と家族用、別のブラウザ・端末では共有せず、同じブラウザ・同じURLを家族で使えば直近記録も共通になります。保存を禁止されたブラウザでは、その訪問中のメモリーだけで継続します。画像不足で展示できない場合、キャンセル、選定失敗は記録せず、部分表示できた展示は実際に表示した作品IDだけを残します。
