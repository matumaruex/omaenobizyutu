# 検証記録

実施日：2026年10月17日（日本時間）。Node.js 24.19.0 / Next.js 16.4.2 / Chromium。

現在のユーザーストーリー：空間に入る → 気持ちの入力 → 同一オリジンの選定API → 実在作品の画像デコード → 散らばった作品を全体表示 → ドラッグ・ピンチで好きな絵を鑑賞 → 再入力、退出。

## 確認した体験と境界

- 入室後は見出し・ロゴ・スティック・現在地・照準を表示せず、「気持ちを教える」と小さな退出だけが残る。
- ブラウザから選定APIへPOSTし、実在する4点以上のIDを受け取り、デコードした画像を3D空間に表示する。
- 4〜12枚すべてで前後差のある散在配置。縦長・横長の4種類の画面比率で、最大画像寸法の全作品が初期表示に収まり、互いに重ならないことを単体試験で確認。
- 最初に最後の作品、次に最初の作品を直接クリック／タップして選び、順路なしで鑑賞できることを確認。
- PCホイールとスマホの二本指ピンチで拡大・縮小、一本指またはマウスのドラッグで移動。操作後も予想される画面位置の作品を正しく選べることを確認。ピンチ・ドラッグが誤って作品を開かないことも確認。
- 鑑賞・入力の開閉後に、拡大・移動した同じ作品を再び選べることを確認。入力中の矢印キーでは背景が動かない。マウス固定は発生しない。
- 全16画像のブラウザでのデコード、実寸の縦横比、作品情報と選定理由の独立した開閉。
- 喪失から期待への再入力で異なる作品群へ更新。退出後の再入室は作品数0に戻る。
- 入力400・異なるOrigin403・未設定AI503・模擬選定502、画像不足、キャンセル後の入力保持。
- 最初の展示から再入室までJavaScript例外・コンソールエラーがないことを確認。未設定だったタブアイコンも追加し、404を解消。
- 単体HTMLはHTTPで読み込んだ後に通信をオフにし、展示・鑑賞・退出まで成功。16点の画像と選定処理を内蔵する。

絵の現れ方は従来の段階的なフェードを維持しています。背景は方向に応じて描く静的なシェーダーで、視点が勝手に動く演出は加えていません。OSの動き低減・品質設定は実装していますが、全端末設定の組合せを網羅してはいません。

AIの契約試験はモックによるもので、有料通信を行っていません。候補数上限・候補ID制約・架空ID拒否・自動再試行なし・`store:false`・失敗時の入力や内部エラーの非開示を確認しています。実サービスの選定品質を確認したものではありません。

## 検証の限界

- 公式APIのライブ収集・最新の権利表記の再照会・公式IIIFの高精細画像取得は通信許可後の検証が必要。
- 実APIキーでのOpenAI応答、日本語の選定品質、実トークン費用は未検証。現在は16点からルールで選ぶ無料デモ。
- iOS Safari／Android実機の性能、OSごとの操作感は未検証。
- 100〜300点へのコレクション拡充、分散利用制限、負荷試験は未実施。
- この環境のブラウザはfile://への直接移動を管理ポリシーで禁止しているため、単体HTMLの直接起動は未検証。

画面キャプチャはテスト時に`artifacts/`へ生成します（Git対象外）。全体表示に加え、拡大・移動した状態も保存します。
